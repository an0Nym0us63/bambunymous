MakerWorld

BambuNymous se branche sur MakerWorld, le site de modèles de Bambu Lab : tes collections, tes j'aime, les créateurs que tu suis, les concours et ton activité de créateur, chaque modèle croisé avec ton historique (« déjà imprimé » ou pas). Tout se trouve dans l'onglet MakerWorld de la page Impressions.

Ce que fait (et ne fait pas) BambuNymous avec MakerWorld

MakerWorld n'a pas d'API publique : BambuNymous lit son API interne, non officielle. Si MakerWorld la change ou la ferme, l'appli continue de marcher normalement ; les fiches retombent simplement sur le lien vers le site.

  • Sans compte, tu as déjà : la fiche de chaque modèle, la recherche, les fils « Découvrir », les concours, la page d'un créateur, les modèles similaires et les commentaires.
  • Avec un compte lié (voir Lier ton compte), tu as en plus : tes collections, tes j'aime, les créateurs que tu suis, ta page de créateur (points, téléchargements…), les boosts, les évaluations et l'ouverture d'un modèle dans Bambu Studio.
  • Partout, chaque modèle est comparé à ton historique : ruban vert ✓ IMPRIMÉ s'il a déjà été imprimé (impressions réussies ou partielles), ruban orange EN COURS s'il est sur le plateau en ce moment, sinon « jamais imprimé ».
  • Titres, descriptifs, profils et commentaires sont affichés en français (traduction fournie par MakerWorld). Quand le texte d'origine diffère, un lien Afficher l'original / Afficher la traduction permet de basculer.
  • Les images sont réduites à la taille affichée (chargement rapide, même sur téléphone). Les GIF sont figés dans les vignettes et animés dans la galerie d'une fiche ; les vidéos tournent en boucle, sans le son.

BambuNymous ne publie rien de lui-même sur MakerWorld. Ce qui s'y écrit (un j'aime, un rangement dans une collection, un boost, une évaluation) part toujours d'un geste de ta part, avec ton compte.

Lier ton compte MakerWorld admin

Le compte MakerWorld se lie dans Paramètres → onglet 🔗 Connexions, carte MakerWorld, bloc « Compte — collections et j'aime ». C'est le compte de la maison : un seul compte MakerWorld pour tout le BambuNymous. Seul un administrateur peut le lier ou le délier.

Tant qu'aucun compte n'est lié, les onglets Collections, J'aime et Suivis affichent « Connecte ton compte MakerWorld dans Paramètres… » : le bon chemin est bien Paramètres → 🔗 Connexions.

Se connecter avec l'e-mail et le mot de passe

  1. Ouvre Paramètres, onglet 🔗 Connexions.
  2. Dans la carte MakerWorld, remplis E-mail du compte Bambu et Mot de passe (jamais enregistré).
  3. Touche Se connecter.
  4. Si Bambu envoie un code par e-mail, l'appli affiche « Bambu a envoyé un code par e-mail : saisis-le. » : tape-le dans Code reçu par e-mail puis touche Valider le code (Annuler pour revenir).
  5. Une fois connecté, la carte montre l'avatar, le nom et le @pseudo du compte, avec un bouton Déconnecter.

Le mot de passe sert une seule fois et n'est jamais gardé. BambuNymous ne conserve qu'un jeton de connexion, qui n'est jamais renvoyé au navigateur ni réaffiché.

Se connecter avec un jeton (double authentification)

Si ton compte Bambu a la double authentification, sa validation n'est pas possible depuis un serveur : l'appli le dit et passe d'elle-même à l'étape « jeton ». Tu peux aussi y aller directement avec le lien discret Coller un jeton plutôt.

  1. Sur makerworld.com, connecté à ton compte, ouvre les outils du navigateur (F12) → Application → Cookies.
  2. Copie la valeur du cookie token.
  3. Colle-la dans le champ Jeton de BambuNymous et touche Enregistrer (Retour pour revenir au formulaire e-mail).

Un jeton dure environ 3 mois. Quand il expire, l'appli affiche « Jeton refusé ou expiré » : recommence l'opération.

Délier le compte

Touche Déconnecter dans la carte. Le jeton est effacé ; les fiches publiques continuent de fonctionner, mais collections, j'aime, suivis et onglet Créateur disparaissent jusqu'à la prochaine connexion.

Le droit « Actions MakerWorld » admin

Un administrateur a ce droit d'office. Pour l'accorder à un compte en lecture seule :

  1. Ouvre Paramètres, onglet 👤 Comptes.
  2. Dans la liste des utilisateurs, coche Actions MakerWorld sur la carte du compte (l'infobulle rappelle : « J'aime, collections, boosts, évaluations et « À faire » avec le compte MakerWorld de la maison »).

La case n'apparaît pas sur les comptes administrateurs (ils l'ont déjà). Décocher la case retire le droit aussitôt.

Sans ce droit, les boutons d'écriture (♡ J'aime, 🔖 Collections, 🚀 Booster, ＋…) sont simplement absents ; l'évaluation se limite au lien vers MakerWorld.

Chez un copain

Quand tu parcours le BambuNymous d'un copain (voir Copains), l'onglet MakerWorld montre ses collections et j'aime. Une pastille indique si un modèle est « déjà chez moi ». 🔖 Collections range alors le modèle dans tes collections. Rien n'est écrit sur le compte du copain, et la tuile À évaluer n'apparaît pas.

L'onglet MakerWorld

Ouvre Impressions puis l'onglet MakerWorld (à côté de Liste, Galerie et À faire). Une barre donne les sous-onglets, l'ouvert en couleur avec son pictogramme : Collections (par défaut), J'aime, Suivis, Découvrir et Créateur (visible seulement quand un compte est lié).

La barre d'actions

Filtre Tous · ✓ Imprimés · Jamais
Sur les listes de modèles, à droite : tous les modèles, ceux déjà imprimés ou ceux jamais imprimés, avec le nombre de chaque. Pratique pour repérer ce qui reste à imprimer dans une collection.

Les listes se chargent avec un squelette de tuiles grisées, puis se complètent en défilant (défilement infini, ou bouton Plus de modèles (n / total)). Ce qui a déjà été vu reste en mémoire le temps de la session : revenir sur un onglet est instantané, la mise à jour se fait en fond. Si quelques fiches manquent encore, la ligne « N modèles en cours de lecture… » l'indique et la liste se recharge seule quelques secondes plus tard.

Si MakerWorld répond mal, un message orange l'indique : « MakerWorld ne répond pas comme prévu : … ». Rien d'autre n'est touché.

La tuile d'un modèle

  • Couverture carrée, avec le ruban ✓ IMPRIMÉ (et une carte teintée de vert) ou ⏳ EN COURS. En haut à droite, un cœur rouge si tu aimes le modèle (sauf dans J'aime, où tous le sont), puis le signet 🔖 (sarcelle) quand le modèle est déjà dans au moins une de tes collections, avec leur nombre s'il y en a plusieurs (chez un copain aussi). Pour ranger un modèle dans tes collections (droit MakerWorld), passe par l'appui long ou le clic droit sur la tuile, ou par la fiche — voir Ranger dans mes collections.

Collections

Le sous-onglet par défaut montre tes collections MakerWorld en grille : une mosaïque des quatre premières couvertures, avec le nom et le nombre de modèles posés dessus. État vide : « Aucune collection. »

En tête de grille, la tuile ⭐ À évaluer (« N modèles imprimés ») apparaît quand tu as imprimé des modèles MakerWorld que tu n'as pas encore évalués. Elle ouvre l'écran décrit dans À évaluer.

Ouvrir une collection

Touche une collection : ses modèles s'affichent en tuiles. Une barre « ‹ 📁 nom », avec le nombre de modèles et combien sont déjà imprimés, reste collée en haut pendant le défilement ; ‹, le geste Retour du téléphone ou le bouton Retour du navigateur referment la collection (sans quitter la page).

Sur la couverture d'un modèle rangé dans la collection depuis BambuNymous, une petite étiquette ＋ nom dit quel compte l'y a ajouté (la date au survol). Un modèle rangé depuis le site ou l'appli MakerWorld, ou avant cette fonction, n'en a pas. Le retirer de la collection efface l'étiquette ; s'il était déjà dedans, le re-ranger ne change pas son auteur.

Créer, renommer, supprimer une collection

Ces gestes demandent le droit MakerWorld et agissent sur MakerWorld.

  • Créer : touche ＋ Collection, tape un nom (60 caractères au plus) dans « Nom de la nouvelle collection », puis Créer (ou Entrée ; ✕ ou Échap pour annuler).
  • Renommer : dans une collection ouverte, touche ✎ ; ou appui long sur la collection → ✎ Renommer. Tape le nouveau nom puis Renommer.
  • Supprimer : dans une collection ouverte, touche 🗑 ; ou appui long → 🗑 Supprimer…. L'appli demande « Supprimer la collection « X » sur MakerWorld ? Les modèles, eux, restent. » ; confirme avec Supprimer.

L'appui long sur une collection propose aussi 📂 Ouvrir.

Ranger un modèle dans mes collections

Touche 🔖 en bas de la fiche d'un modèle, 🔖 Ranger dans mes collections… dans le menu d'appui long d'une tuile, ou le signet d'une tuile déjà rangée. La fenêtre « Ranger dans mes collections » (le nom du modèle sous le titre) liste tes collections, une carte chacune avec une case à cocher et leur effectif ; celles qui contiennent déjà le modèle sont cochées et teintées d'orange.

  1. Coche les collections où le modèle doit être, décoche celles d'où il doit sortir : une pastille + ajout ou − retrait montre ce qui changera. Au-delà de 8 collections, un champ Chercher une collection… aide à trouver.
  2. Pour une nouvelle collection : ＋ Nouvelle collection, tape le nom, Créer ; elle arrive déjà cochée.
  3. Touche Enregistrer · N collections (actif seulement si quelque chose a changé ; N est le nombre de collections qui contiendront le modèle).

MakerWorld remplace à chaque enregistrement la liste complète des collections du modèle. Si l'appli n'arrive pas à lire où il se trouve déjà, elle bloque l'enregistrement plutôt que de risquer de le retirer des autres collections, et le dit.

J'aime

Le sous-onglet J'aime liste les modèles que tu as aimés sur MakerWorld, du plus récent au plus ancien, avec les mêmes tuiles, le même filtre et le même menu que les collections. Quand tu retires un j'aime depuis une fiche, le modèle quitte aussitôt la liste.

Suivis : les créateurs que tu suis

Le sous-onglet Suivis rassemble les modèles récents des créateurs que ton compte MakerWorld suit, tous mélangés du plus récent au plus ancien, avec la date de publication sur chaque tuile. Ils s'affichent en frise : d'abord les 7 derniers jours, puis, en descendant, des périodes de plus en plus longues (14 jours, 28, puis 60 au plus) ; le bouton du bas dit jusqu'où on est remonté (« avant le 12 oct. »). La période suivante est préparée à l'avance, et une semaine sans nouveauté remonte d'elle-même jusqu'aux derniers modèles. Même avec des centaines de créateurs suivis, l'ouverture est donc rapide.

Ne voir que certains créateurs

  1. Touche 👤 Tous les créateurs (N).
  2. Dans « Créateurs suivis », cherche un nom ou un pseudo (Chercher un créateur…, les accents ne comptent pas) et coche ceux qui t'intéressent. Voir ses modèles › ouvre directement la page d'un créateur.
  3. Touche Voir K créateurs. Le bouton devient 👤 K créateurs ; le ✕ à côté revient à tous. Tous, dans la fenêtre, décoche tout.

Avec 5 créateurs ou moins, l'appli montre jusqu'à 40 modèles par créateur ; au-delà, les 10 derniers de chacun.

Pour être prévenu des nouveaux modèles de certains créateurs, utilise la notification « Nouveau modèle d'un créateur suivi » (voir Notifications MakerWorld).

Concours

Dans Découvrir, touche 🏆 Concours. Des puces filtrent la liste : En cours (par défaut), Délibération, Terminés et Tous, chacune avec son nombre.

Chaque carte de concours montre :

  • la bannière et une pastille d'état : En cours (vert), Délibération (orange), Terminé (gris) ou À venir (bleu) ;
  • l'échéance : « jusqu'au 01/11 · encore 9 jours », « dernier jour », « résultats le … », « à partir du … » ou « terminé le … » ;
  • le nom, la description et « N modèles · N participants · N vues » ;
  • 🎁 Récompenses ▾ : la liste des lots par rang (🥇🥈🥉, « ×3 » quand plusieurs gagnants partagent un rang) ;
  • deux lignes de vignettes : EN VUE (les modèles populaires d'un concours en cours) ou PRIMÉS (les gagnants d'un concours terminé, avec leur médaille) ; un ✓ marque ceux que tu as imprimés ;
  • Voir les N modèles du concours › et le lien Voir le concours sur MakerWorld ↗.

La fenêtre des modèles d'un concours propose la bascule 🔥 Populaires / 🆕 Récents, 20 modèles par page et Plus de modèles (n / total). Touche un modèle pour ouvrir sa fiche.

Créateur : ton activité sur MakerWorld

Si tu publies tes propres modèles, le sous-onglet Créateur (visible quand un compte est lié) résume ton activité : points, abonnés, téléchargements, impressions, boosts et j'aime.

La carte de créateur

  • En-tête : avatar, nom, @pseudo et niveau ; à droite le solde 🪙 points, avec le détail « X normaux · Y exclusifs » (les points exclusifs viennent des modèles publiés en exclusivité sur MakerWorld).
  • Pastilles : nombre d'abonnés, nombre de modèles publiés, et « N boosts à donner » (les boosts que tu peux offrir à d'autres créateurs).
  • POINTS GAGNÉS (pleine largeur) : le total gagné depuis toujours, et les gains sur 7 j, 30 j et 1 an.
  • TÉLÉCHARGEMENTS, IMPRESSIONS, BOOSTS REÇUS, J'AIME : le total de ton compte, et la progression sur 7 j, 30 j et 1 an. Un « ≥ » signale que l'appli n'a pas de relevés sur toute la période (le chiffre réel est au moins celui-là) ; « — » qu'il est inconnu.

Sous la carte, une bascule à deux positions : 🧩 Mes modèles (N) et 🪙 Historique des points.

Les graphiques jour par jour (points, gains, compteurs) sont dans la tuile MakerWorld de l'accueil, en grand format.

Mes modèles : le classement

Tes modèles, classés du plus au moins performant selon les deux premiers menus, ou par date de publication avec le troisième :

Type
Points (par défaut), Téléchargements, Impressions, Boosts, J'aime.
Période
7 jours, 30 jours (par défaut), 90 jours, 1 an, Depuis le début.
Tri
Meilleurs (par défaut, selon le type et la période), Plus récents ou Plus anciens : par date de publication, rappelée sous chaque modèle (« publié le 20 oct. 2026 »). Le chiffre à droite suit toujours le type et la période.

Chaque ligne montre la couverture, le titre (« · exclusif » le cas échéant), les compteurs « ⬇️ téléchargements · 🖨️ impressions · 🚀 boosts · ❤ j'aime », et à droite le gain sur la période. En mode Points, une ligne précise d'où viennent les points : modèle, profil (profils d'impression publiés) et 🚀 boosts. Touche une ligne pour ouvrir la fiche du modèle.

Pour les types autres que les points, une ligne « Tout le compte, 30 jours : ⬇️ +N 🖨️ +N 🚀 +N ❤ +N » donne la progression de tout le compte.

Pourquoi certains chiffres sont partiels. MakerWorld ne donne que des totaux pour les téléchargements, impressions, boosts et j'aime. BambuNymous relève donc ces compteurs chaque jour (et garde 400 jours de relevés). Si la période choisie remonte avant le premier relevé, une note orange l'explique : ces compteurs ne sont comptés que depuis cette date. Les points, eux, sont toujours complets.

Importer l'historique admin

Pour avoir des totaux complets dès le départ, un administrateur peut importer une seule fois l'historique de son compte :

  1. Touche Copier le script de console.
  2. Sur makerworld.com, connecté, ouvre la console du navigateur (F12) et colle le script : il lit la vue d'ensemble de ton compte et de chacun de tes modèles, puis télécharge le fichier mw-historique.json. Le script ne fait que lire, avec ta propre session ; rien n'est envoyé ailleurs.
  3. Dans BambuNymous, touche Importer l'historique (fichier) et choisis ce fichier.

L'appli confirme « Historique importé : N jours, du … au …, et M modèles un par un. » Le lien disparaît ensuite (ou devient Réimporter l'historique si seuls les totaux du compte ont été importés).

Historique des points

🪙 Historique des points liste tes versements de points, regroupés par jour (« lun. 20 oct. ») avec le total du jour en vert (ou en rouge s'il est négatif). Chaque ligne indique l'origine (Modèle, Profil, Boost…), le titre du modèle (et du profil), une mention excl. pour un bonus de points exclusifs, et le nombre de points. Touche une ligne pour ouvrir la fiche du modèle ; Plus anciens (n / total) charge la suite.

La fiche d'un modèle

Touche n'importe quelle tuile MakerWorld (collection, j'aime, découvrir, concours, page créateur, carte MakerWorld d'une impression…) : la fiche s'ouvre en grand panneau (centré sur ordinateur). En haut à droite, par-dessus la galerie : une ⭐ dorée si le modèle attend ton évaluation (la toucher l'ouvre, comme l'étoile de la barre du bas), ⋯ pour le menu des actions et ✕ pour la fermer. Elle s'affiche tout de suite avec la couverture et le titre, puis se complète.

Galerie, titre et compteurs

  • Galerie horizontale : les images du créateur et les photos d'impressions réelles (30 au plus), avec « 1 / 3 » sur chacune. Glisse de côté ; touche une image pour la voir en plein écran. Sur ordinateur, tire la bande à la souris ou utilise les flèches ‹ › sur ses bords.
  • La ligne 🌐 MAKERWORLD et la licence (BY-NC…), le titre en français, et le titre d'origine en gris s'il diffère.
  • « par créateur », avec son avatar (touche le nom pour sa page), et la date de publication.
  • Compteurs, en tuiles de couleur : ❤ j'aime, ⬇ téléchargements, 🖨 impressions, 🔖 collections, 💬 avis (« 1.2k » = 1 200).
  • Bandeau d'état : « ✓ Imprimé · N impressions » (vert) avec le bouton voir mes prints, ou « ⏳ En cours d'impression » (orange).
  • Les catégories, en puces.

Les actions

En bas, toujours à portée du pouce, une rangée de boutons (les mêmes symboles que sur MakerWorld). Un bouton en retrait (pointillés, couleur pâle) n'est pas disponible : touche-le, un message dit pourquoi.

🖥️ Studio
Le grand bouton vert, sur ordinateur (droit MakerWorld) : ouvre Bambu Studio sur le fichier 3MF du profil retenu (ou choisi automatiquement, voir Profils). Compte comme un téléchargement sur MakerWorld. Sans ce droit, ou sans profil, le bouton devient 🌐 ↗ (la page du modèle sur MakerWorld).
📱
Sur téléphone ou tablette, à la place du précédent : ouvre le modèle dans l'appli Bambu Handy.
♡ / ❤
Compte lié et droit MakerWorld : aime le modèle (ou retire le j'aime), en rouge. Le bouton change tout de suite, la liste J'aime suit.
🚀
Droit MakerWorld : booster le modèle (voir 🚀 Booster ci-dessous). Si tu l'as déjà boosté, une pastille le dit (✓, ou le nombre de fois). En retrait quand ce n'est pas possible : le toucher donne la raison (« Déjà boosté (1/1 pour ce modèle) », « Plus aucun boost disponible », limite par créateur).
🔖
Droit MakerWorld : ranger le modèle dans tes collections. Une pastille donne le nombre de tes collections qui le contiennent déjà.
⭐
Orange quand le modèle attend ton évaluation (voir Noter un modèle) : ouvre directement l'écran d'évaluation (ou MakerWorld si l'évaluation ne peut pas se faire depuis l'appli). En retrait sinon : le toucher dit « Pas encore imprimé » ou « Déjà évalué ». Absent chez un copain.

Profils d'impression et plateaux

La section 🧩 Profils (N) liste les profils d'impression du modèle, chacun replié. Les 4 premiers s'affichent, puis Voir les N autres profils. Le profil retenu pour « À faire » vient toujours en premier, sur une carte teintée de vert ; le profil déplié est teinté de bleu. Quand le profil a sa propre image sur MakerWorld, elle sert de vignette à gauche de son nom ; déplié, il montre ses illustrations dédiées en petite bande (touche une image pour l'agrandir).

Sur chaque profil replié :

  • le titre (★ si c'est le profil par défaut du créateur) et « ✓ k/n » si tu as déjà imprimé k plateaux sur n ;
  • une ligne de détails : imprimante, nombre de plateaux, poids, durée, hauteur de couche, remplissage, nombre d'impressions sur MakerWorld ;
  • des badges : Retenu (le profil choisi automatiquement), 🖨️ pour ta H2D (fait pour ton imprimante), 🖨️ compatible H2D ou pas pour ta H2D, ✏️ du créateur ou « par auteur », la note « ⭐ 4,8 (120 avis) » ;
  • un résumé du stock : « 🧵 3 filaments · tous en stock », « 2 en stock » ou « rien d'approchant en stock ».

Le choix automatique privilégie, dans l'ordre : un profil imprimable sur ton imprimante, publié par le créateur, fait pour ton modèle d'imprimante, le mieux noté, puis le profil par défaut. Ton imprimante est celle réglée dans Paramètres → Imprimante (champ Modèle), sinon elle est déduite du numéro de série, sinon de ton historique.

Profil déplié

📌 Retenir pour « À faire »
Droit MakerWorld : la file À faire utilisera ce profil, ces plateaux et ces filaments. Le bouton confirme « ✓ Retenu ». Ensuite il devient 📌 Retenu pour « À faire » · mettre à jour (« ✓ Mis à jour ») ; le ✕ à côté oublie ce choix.
🖥️ Ouvrir ce profil dans Bambu Studio
Sur ordinateur, droit MakerWorld. Sur téléphone : 📱 Ouvrir ce profil dans Bambu Handy.
🔎 Filaments exacts (finition, référence) — lire le 3MF
Droit MakerWorld. Par défaut, l'appli ne connaît que la matière et la couleur de chaque filament. Ce bouton télécharge une seule fois le fichier 3MF du profil pour lire la finition, la marque et la référence exactes. L'appli prévient avant : ça compte comme un téléchargement sur MakerWorld.

Correspondance avec ton stock. Pour chaque filament du profil, l'appli propose la bobine de ton stock de même matière à la couleur la plus proche, avec un niveau (« identique », « très proche », « proche », « approchant », « couleur différente ») et la quantité restante ou manquante. changer ▸ permet de choisir une autre bobine (onglets Dans l'AMS et Autre matière, ou chercher dans mon stock ▸).

Plusieurs plateaux. Le besoin en filament est calculé pour tous les plateaux ; touche un plateau pour l'enlever du calcul (Tous pour tout reprendre). L'appli résume : « ▶ À lancer maintenant avec l'AMS : plateaux 1, 3 » et « ↻ Déjà imprimés, relançables avec l'AMS : plateau 2 ».

Plateaux retenus. Au-dessus de « À lancer », la ligne « Plateaux retenus : … » dit où tu en es, série par série (« 2/4 faits », « 2e série : 2/4 faits », « 4/4 faits ×2 ») ; voir À faire.

Grille des plateaux. Chaque plateau montre sa vignette recolorée avec les couleurs choisies, son nom, son poids et sa durée, et des badges : ⏳ EN COURS, ✓ FAIT 2× (bordure verte : déjà imprimé, avec le nombre de fois), ↻ 1× avant (imprimé lors d'une série précédente, à refaire pour la série en cours), ▶ PRÊT (AMS) (bordure bleue : tous ses filaments sont dans l'AMS en quantité suffisante) ou à charger. Les pastilles de couleur sous un plateau permettent un choix propre à ce plateau (🎨).

Commentaires, modèles similaires et tags

  • 💬 Commentaires (N), une carte repliée par défaut (touche son titre pour la déplier ou la replier) : auteur, date, étoiles, texte (traduit, avec l'original à la demande), photos, « ♥ N ». S'il a des réponses, 💬 R réponses ▶ les déplie en fil, en retrait : chacune avec son auteur (la pastille créateur pour l'auteur du modèle), « ↪ à Untel » quand elle répond à quelqu'un, sa date, son texte traduit (l'original à la demande), ses photos et ses ♥ ; les premières s'affichent tout de suite, les autres se chargent à l'ouverture. 10 commentaires par page, puis Plus de commentaires (n / total).
  • ✨ Modèles similaires : une rangée de 12 modèles proches (avec ✓ IMPRIMÉ) ; en toucher un remplace la fiche.
  • Les tags (#mot) terminent la fiche.

Associer un modèle à des impressions admin

Quand une impression a été lancée depuis Bambu Studio ou une carte SD, l'appli ne sait pas toujours de quel modèle MakerWorld elle vient. 🔗 Associer à un print (fiche ou menu d'une tuile) répare ça :

  1. La fenêtre « 🔗 Associer à des impressions » s'ouvre au-dessus de ton historique, avec la couverture et le nom du modèle en tête.
  2. Cherche avec Chercher une impression (nom, fichier, filament…). La case Seulement les impressions sans modèle MakerWorld, cochée par défaut, ne montre que celles qui n'ont pas encore de lien ; décoche-la pour tout voir.
  3. Touche les impressions concernées (une coche violette les marque), puis ✓ Associer (N). Si certaines avaient déjà un autre modèle, l'appli prévient qu'il sera remplacé.

Pour rattraper d'un coup les vieux prints, voir aussi Historique cloud Bambu.

La page d'un créateur

Touche le nom d'un créateur (« par nom ») sur une tuile ou une fiche, ou Voir ses modèles › dans le choix des créateurs suivis. Un panneau s'ouvre :

  • En-tête : son avatar dans un anneau de couleur (son initiale s'il n'en a pas), son nom, ses pastilles (@pseudo, abonnés, modèles, 🏆 concours gagnés s'il en a), et ✕ (ou Échap) pour fermer.
  • Tuiles : ⬇ téléchargements, 🖨️ impressions, ❤ j'aime, 🚀 boosts.
  • Ses modèles (24 par page, ⬇ Plus de modèles (n / total)), avec ✓ IMPRIMÉ et une carte teintée de vert pour ceux que tu as déjà imprimés, et « ❤ N · 🖨️ N ». Les pastilles Tous, ✓ Imprimés et Jamais filtrent les modèles déjà chargés. Touche un modèle pour ouvrir sa fiche.
  • En bas, 🌐 Voir sur MakerWorld ↗ ouvre sa page sur le site, et, à droite, 📣 Partager admin l'envoie sur Telegram comme un modèle : son nom, @pseudo, abonnés, modèles, j'aime, téléchargements, impressions, concours gagnés, combien de ses modèles tu as imprimés (parmi ceux affichés), et le lien. Images à cocher : son avatar et les couvertures de ses modèles ; sans image, Telegram affiche la carte du lien.

Noter les modèles imprimés

MakerWorld demande d'évaluer les modèles que tu imprimes. BambuNymous liste ceux qui attendent ton avis, avec tes photos de l'impression prêtes à joindre, et publie l'évaluation pour toi (droit MakerWorld).

  • La tuile ⭐ À évaluer en tête des Collections ouvre la liste complète.
  • Dans la fiche d'un modèle qui attend ton évaluation, une étoile en haut mène au bandeau orange et à son bouton ⭐ Évaluer.
  • La fiche d'un groupe d'impressions propose d'évaluer tous ses modèles d'un coup.

L'écran « À évaluer » (étoiles, messages tout faits, photos, Publier l'évaluation, Oublier sans évaluer) est décrit en détail dans À évaluer. Les modèles retenus pour être imprimés plus tard se gèrent dans la file À faire.

Les messages tout faits proposés à 5 étoiles se règlent dans Paramètres → 🔗 Connexions → ⭐ Messages d'évaluation.

Réglages MakerWorld (Paramètres)

Les réglages MakerWorld sont dans Paramètres → onglet 🔗 Connexions. Cet onglet est réservé aux administrateurs ; la carte des messages d'évaluation y est aussi visible pour un compte ayant le droit Actions MakerWorld.

Fiches des modèles imprimés admin

BambuNymous garde en mémoire la fiche MakerWorld (titre traduit, couverture, créateur, catégories, compteurs, profils) de chaque modèle que tu as imprimé : c'est ce qui affiche la carte MakerWorld dans la fiche d'une impression et permet de chercher dans l'historique par titre, tags ou catégories.

La ligne d'état indique « N fiches sur M modèles imprimés », puis éventuellement « · K introuvables » (modèles retirés de MakerWorld), « · E à réessayer » et « · relecture en cours… ».

⟳ Relire maintenant
Relit en arrière-plan les fiches manquantes, en erreur ou anciennes (« Relecture lancée en arrière-plan (1,5 s par modèle). », ou « Une relecture tourne déjà. »). Sans rien faire, l'appli s'en charge toute seule toutes les 6 heures, et relit une fiche quand elle a plus de 30 jours.

Compte admin

Le bloc « Compte — collections et j'aime, avec « déjà imprimé » » : connexion par e-mail, code, jeton et déconnexion, décrits dans Lier ton compte MakerWorld.

Historique cloud Bambu admin

Visible quand un compte est lié. Il retrouve le modèle MakerWorld (et son profil) des impressions qui n'en ont pas, d'après tes impressions enregistrées dans le cloud Bambu : par numéro de tâche, sinon par heure de début (à 10 minutes près, et seulement si une seule impression correspond). Il ne remplit que les liens vides et n'écrase jamais un lien existant.

  1. Touche Analyser. Le bilan s'affiche : « T impressions cloud avec modèle · M retrouvées dans l'appli · N liens à ajouter (x par tâche, y par heure) · P profils », avec quelques exemples « impression → modèle ».
  2. Si le bilan te convient, touche Appliquer (N liens, P profils). L'appli confirme « ✓ Appliqué : … ».

Diagnostic de l'API admin

Un repli Diagnostic de l'API (compte lié) propose des boutons qui interrogent MakerWorld et affichent sa réponse brute, avec 📋 Copier. C'est un outil technique, utile seulement pour signaler un problème quand MakerWorld a changé quelque chose.

⭐ Messages d'évaluation

Quand tu évalues un modèle à 5 étoiles, l'appli peut proposer un message tout fait, tiré au hasard dans une famille de messages, que tu modifies avant de publier. Cette carte gère ces familles (administrateur ou droit Actions MakerWorld).

  • Touche une famille pour la déplier : son nom (Nom de la famille) et ses messages, chacun modifiable, avec ✕ pour en retirer un.
  • + Message ajoute un message ; + Famille une nouvelle famille ; Supprimer la famille l'efface après confirmation.
  • La première famille est proposée d'office (mention « par défaut ») ; ⭐ Mettre par défaut fait passer une autre famille en tête.
  • Dans les messages, {modèle} et {créateur} sont remplacés automatiquement par le titre du modèle et le nom du créateur.
  • Touche Enregistrer (actif seulement quand quelque chose a changé). L'appli affiche « Enregistré ».

Le modèle de ton imprimante

Dans Paramètres → 🖨️ Imprimante, le champ Modèle (par défaut « Automatique », d'après le numéro de série) sert à MakerWorld : profil fait pour ton imprimante, badges de compatibilité, fichier ouvert dans Studio.

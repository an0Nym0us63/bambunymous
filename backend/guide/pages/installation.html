Installer et configurer

Pas à pas, pour qui n'a jamais installé de serveur : de rien du tout à BambuNymous qui suit ton imprimante, en une demi-heure environ.

Ce qu'il te faut

BambuNymous est un petit serveur qui tourne chez toi, sur ton réseau, et que tu ouvres dans le navigateur (ordinateur ou téléphone). Il lui faut :

  • une machine allumée en permanence, sur le même réseau que l'imprimante : un NAS (Synology, QNAP…), un Raspberry Pi 4 ou 5, un mini PC, un serveur maison. Un ordinateur de bureau marche aussi, mais l'appli ne suit l'imprimante que quand il est allumé ;
  • Docker sur cette machine (le logiciel qui fait tourner l'appli dans sa boîte, sans rien installer d'autre) ;
  • ton imprimante Bambu Lab branchée au réseau, avec trois informations lues sur son écran : son adresse IP, son numéro de série et son code d'accès (code LAN).

Tout reste chez toi : la base de données, les photos et les réglages vivent sur ta machine. Rien ne passe par un service extérieur, sauf ce que tu branches toi-même (MakerWorld, copains, notifications).

1. Installer Docker

NAS Synology
Centre de paquets → Container Manager → Installer.
NAS QNAP
App Center → Container Station → Installer.
Raspberry Pi, Linux
Dans un terminal : curl -fsSL https://get.docker.com | sh, puis sudo usermod -aG docker $USER et reconnecte-toi.
Windows, Mac
Installe Docker Desktop depuis docker.com et lance-le une fois.

Si tu as déjà Portainer, tu peux tout faire depuis son interface (voir plus bas).

2. Préparer les deux fichiers

Crée un dossier bambunymous sur la machine (sur un NAS, dans un partage, par exemple docker/bambunymous). Mets-y deux fichiers texte.

Le fichier compose.yaml

Il dit à Docker quelle appli lancer et où garder ses données :

services:
  bambunymous:
    image: ghcr.io/an0nym0us63/bambunymous:latest
    container_name: bambunymous
    restart: unless-stopped
    ports:
      - "7914:8000"
    volumes:
      - bambunymous_data:/data
    environment:
      - DATA_DIR=/data
      - DATABASE_URL=sqlite+aiosqlite:////data/bambunymous.db
      - UPLOADS_DIR=/data/uploads
    env_file:
      - .env

volumes:
  bambunymous_data:

7914 est le port où tu ouvriras l'appli ; change-le s'il est déjà pris sur ta machine (par exemple "8090:8000").

Le fichier .env

Une seule ligne obligatoire : une clé secrète, qui protège les connexions. Mets une longue suite de lettres et de chiffres au hasard, que personne ne connaît :

SECRET_KEY=remplace-moi-par-une-longue-suite-au-hasard-8f3k2l9q

Ne garde pas l'exemple ci-dessus tel quel, et ne partage jamais ce fichier. Sous Linux, openssl rand -hex 32 en fabrique une. Si tu la changes plus tard, tout le monde devra se reconnecter (rien n'est perdu).

3. Lancer l'appli

Dans un terminal ouvert dans le dossier bambunymous :

docker compose up -d

Docker télécharge l'appli (quelques centaines de Mo la première fois) puis la démarre. Elle redémarrera toute seule avec la machine.

Avec Portainer

Stacks → Add stack → nomme-la bambunymous, colle le contenu de compose.yaml dans l'éditeur, et dans Environment variables ajoute SECRET_KEY avec ta clé (retire alors les deux lignes env_file du texte collé). Puis Deploy the stack.

Avec Container Manager (Synology)

Projet → Créer → choisis le dossier bambunymous : il trouve compose.yaml tout seul. Valide, il construit et démarre le projet.

4. Première connexion

  1. Ouvre http://ADRESSE-DE-LA-MACHINE:7914 dans ton navigateur (par exemple http://192.168.1.20:7914 ; sur la machine elle-même, http://localhost:7914).
  2. Connecte-toi avec l'identifiant admin et le mot de passe admin.
  3. Change tout de suite ce mot de passe : Paramètres › Comptes › Mon compte. Tant qu'il reste « admin », n'importe qui sur ton réseau peut entrer.
  4. Si tu veux, active la double authentification et crée un compte pour chaque personne de la maison (Utilisateurs).

5. Brancher l'imprimante

Sur l'écran de l'imprimante, relève :

Adresse IP
Réglages → Réseau (ou WLAN) : quatre nombres comme 192.168.1.42. Pour qu'elle ne change pas, réserve-la dans ta box internet (bail DHCP fixe).
Code d'accès
Au même endroit : le code d'accès (Access Code), 8 caractères.
Numéro de série
Réglages → Appareil (ou À propos) ; aussi dans Bambu Studio et Bambu Handy.

Puis dans BambuNymous : Paramètres › Imprimante, remplis les trois champs et touche Sauvegarder. La connexion part dès que les trois sont renseignés : en quelques secondes l'accueil montre l'état de l'imprimante et ses AMS.

Rien ne s'affiche ? Vérifie que l'imprimante et la machine sont sur le même réseau (pas un réseau invité), que l'adresse est la bonne, et que le code d'accès n'a pas changé (il change si on le régénère sur l'imprimante). Le journal du serveur dit ce qui coince.

6. Et ensuite

L'appli marche dès maintenant. Pour en tirer tout le parti, dans l'ordre qui te plaît :

  • tes filaments : crée tes références et tes bobines (Filaments), ou scanne leurs étiquettes NFC avec l'appli Android ;
  • le tarif de l'électricité (Paramètres › Imprimante) pour le coût de chaque impression ;
  • ton compte MakerWorld (Paramètres › Connexions) : liste « À faire », planning, collections, évaluations ;
  • les notifications (Paramètres › Notifs) : fin d'impression, pause, humidité, sur le téléphone ;
  • les copains (Paramètres › Connexions) pour voir le BambuNymous de tes amis ;
  • la sauvegarde vers un NAS (Paramètres › Outils), si tu en as un.

Mettre à jour

La ligne de version te dit quand une nouvelle version existe. Pour l'installer, dans le dossier bambunymous :

docker compose pull
docker compose up -d

Avec Portainer : ouvre la stack et Update the stack en cochant Re-pull image. Tes données ne bougent pas : elles vivent dans le volume bambunymous_data, pas dans l'appli.

Où sont mes données, et les sauvegarder

Tout est dans le volume Docker bambunymous_data : la base (bambunymous.db), les photos, les 3MF, les vues 3D. Ne supprime jamais ce volume (docker compose down -v l'effacerait). Pour une sauvegarde automatique chaque nuit vers un NAS, monte le dossier du NAS sur /nas dans compose.yaml :

    volumes:
      - bambunymous_data:/data
      - /chemin/vers/le/partage/du/nas:/nas

puis active-la dans Paramètres › Outils › Sauvegarde et NAS.

Y accéder hors de chez toi

Par défaut, l'appli ne s'ouvre que depuis ton réseau. Pour l'ouvrir de partout (et recevoir les notifications sur le téléphone hors du Wi-Fi), le plus sûr est un VPN vers chez toi (WireGuard, Tailscale, celui de ta box ou de ton NAS) : rien n'est exposé sur internet. Sinon, un reverse proxy en HTTPS (Nginx Proxy Manager, Traefik, le proxy inversé de Synology) avec un nom de domaine ; dans ce cas, mot de passe solide et double authentification obligatoires.
